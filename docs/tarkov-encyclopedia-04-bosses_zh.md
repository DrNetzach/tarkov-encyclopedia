## 详细档案

### 🎯 Reshala（海关 Boss）

- **真名：** Dmitri；"Reshala" 在俄语俚语中意为"摆平者/解决问题的人"
- **主场：** Customs（宿舍楼 / 新加油站 / 要塞三处轮换，约 60–75%）+ Terminal（轮换池成员之一）
- **HP：** 752（头 62 / 胸 145 / 腹 125 / 手臂 100×2 / 腿 110×2）
- **护卫：** 4 名积极进攻的重武装护卫（以手雷和曳光弹宣告存在；护卫本身穿 6 级甲，是真正的威胁）
- **签名物品：** 黄金 TT 手枪、宿舍钥匙
- **性格：** 经营 Customs 残存的地下犯罪世界；**偏好求生而非正面战斗** —— 护卫冲锋时他在后方转移阵地，玩家清完护卫后常被他从暗处一枪收掉
- **地位：** 大多数玩家遇到的第一个 Boss，为所有 Boss 战树立模板

### 🎯 Tagilla（工厂 Boss）

- **主场：** Factory（白天约 50% / 夜间约 60%）+ Interchange（Goshan 下方停车场）+ Terminal（轮换池成员之一）
- **HP：** 1,220（头 100 / 胸 320 / 腹 260 / 手臂 130×2 / 腿 140×2）
- **形象：** 戴焊接面罩（"UBEY"款）的光头巨汉，手持大锤 —— 塔科夫版跳杀
- **战斗风格：** 混合装备 —— **远程 Saiga-12K 或 MP-155 霰弹枪，近战大锤**；一旦决定冲锋即直线逼近，大锤一击致命；移动迅速、闪避枪火
- **护甲：** **护甲仅覆盖胸部**（头、腹相对裸露）+ 焊接面罩；高穿弹打头、高肉伤打腹均可
- **Lore 花絮：** 曾在疗养院下方的 Labyrinth 中戏弄闯入的 PMC 小队
- **护卫：** 独行为主，个别地图可能有 Scav 随行

### 🎯 Shturman（森林 Boss）

- **主场：** Woods —— Priozersk 自然保护区内的**锯木厂**（Sawmill）
- **HP：** **812**（头 62 / 胸 180 / 腹 150 / 手臂 100×2 / 腿 110×2）
- **护卫：** 2–3 名大口径武器追随者（均使用 SVD 类步枪，远距致命）
- **签名物品：** SVD 狙击步枪、Shturman 的储物钥匙、Red Rebel 冰镐（掉落池）
- **性格：** 神射手型 Boss —— 通过光学瞄具追踪目标直至手下逼近完成击杀；偏好远程、锁定目标前可能先开 3–5 枪警告；**很多人到死没发现射手位置**
- **领地传闻：** PMC 们避免进入保护区森林，怕误入其伏击圈

### 🎯 Sanitar（海岸线 Boss）

- **真名/身份：** 前 TerraGroup Labs 外科医生，**选择不随其他员工撤离**（"Sanitar"在俄语中意为"卫生员/护理员"）
- **主场：** Shoreline —— **码头（Pier）、温室（Greenhouses）一带（tarkov.dev 实时数据）；疗养院内已无固定刷点**，概率游荡至别墅区、气象站/水电站 + Terminal（轮换池成员之一）
- **HP：** **1,270**（分项随版本调整，本卷仅列经核验的总数）
- **护卫：** 2–3 名重装甲护卫（5 级护甲 + 面罩头盔，口袋装满手雷）
- **核心能力：** **战斗中自我治疗** —— 携带手术包、注射器、绷带、止痛药，受伤后回血
- **战斗风格：** 受伤后积极冲锋，使用手雷与侧翼包抄；护卫攻击性强
- **掉落：** Sanitar 手术包、检眼镜、SICC 箱、LEDX、蓝卡等稀有钥匙卡、注射器箱
- **弱点：** 中远距离交战能力一般，近距离致命

### 🎯 Killa（立交桥 Boss）

- **真名：** Ivan Ivanovich（伊万·伊万诺维奇）
- **主场：** Interchange ULTRA 购物中心 —— **IDEA、OLI、Goshan、中央店铺及停车场均可能刷新**（无官方百分比分布，总刷新约 **45%**）+ Terminal（约 20%）
- **HP：** **890**（头 70 / 胸 210 / 腹 170 / 手臂 100×2 / 腿 120×2）
- **护卫：** 无 —— 独狼
- **装备：** Maska-1SCh 头盔 + **6 级防弹面罩**、6B13 突击护甲（5 级）、**RPK-16（95 发弹鼓）**、AK-74 备用
- **性格/行为：** 守卫 ULTRA 商场期间丧失理智，将每个入侵者视为猎物 —— **会主动猎杀你**：Z 字形冲锋、边射边持续移动、追击不休（"追到地图外"的社区梗即源于此）；烟雾弹遮蔽 → RPK 压制 → 冲锋 → 快速换弹
- **战利品：** 一个行走的宝箱 —— Killa 面罩（高价）、6B13 护甲、稀有钥匙卡
- **弱点：** 腿部完全无甲（120 HP/条）；高穿甲弹可击穿面罩

### 🎯 Glukhar（储备站 Boss）

- **身份：** 前军官，占领联邦储备局军事基地
- **主场：** Reserve（军事基地、火车站、地下仓库）+ Terminal（轮换池成员之一）
- **HP：** **1,010**（头 70 / 胸 220 / 腹 140 / 手臂 145×2 / 腿 145×2）
- **护卫：** **6 名精英护卫**，分三种 AI 类型 —— **突击型（Assault，激进冲锋，760 HP）/ 守卫型（Security，贴身保护，806 HP）/ 侦察型（Scout，区域巡逻，580 HP）**；护卫穿戴 5–6 级护甲
- **特点：** 全游戏装备最精良的护卫团队，群体作战极其危险；常在黑象（Black Bishop）与地下层之间移动
- **掉落：** 高级军用装备、钥匙、文件、顶级弹药（ASH-12 等）

### 🎯 Kaban（街区 Boss）

- **名字含义：** "Кабан" = 野猪
- **身份：** 军火商，曾经营合法小企业后转向犯罪（其生意与执法系统的暧昧关系由来已久）；控制 Streets 东部的 **LexOs 汽车经销商**大院
- **主场：** Streets of Tarkov —— LexOs 车行
- **HP：** 1,300（头 85 / 胸 355 / 腹 260 / 手臂 150×2 / 腿 150×2）
- **护卫：** **8 名** —— 副官 **Basmach 与 Gus**、4 名守卫（4–5 级甲）、2 名屋顶狙击手
- **武器：** **PKP "Pecheneg" 7.62×54R 步兵机枪**（100 发弹链，压制极强）
- **防御设施：** **AGS-30 自动榴弹发射器 + NSV 重机枪**（固定武器）、克莱莫地雷；大院以沙袋、铁丝网、车辆路障加固
- **性格/战斗风格：** **不穿戴护甲** —— 1,300 HP 全部落在肉上，高穿头两枪即可终结，但固定武器与 8 人交叉火力才是真正的杀局；体型巨大无法快速移动，护卫死后会躲进建筑；其追随者从不离开 LexOs 领地
- **掉落：** 车行密室钥匙（约 85 万卢布，实时）、PKP、实验室钥匙卡
- **关系：** 与 Kollontay 关系良好（互相庇护）

### 🎯 Kollontay（中心区 / 街区 Boss）

- **身份：** 前 MVD（内务部）官员，以暴力执法闻名，同事又恨又怕；合约战争期间占据市中心 MVD 学院
- **主场：** Ground Zero（**仅 21+ 级匹配**，无固定刷新点，几乎全图随机）或 Streets（商场 / 内务部学院各 50%）
- **HP：** 1,055（分项随版本调整，本卷仅列经核验的总数）
- **护卫：** 4 人（霰弹枪、冲锋枪、突击步枪、闪光弹）
- **装备：** AKMN 7.62×39 突击步枪 / **RPD·RPDN 7.62×39 机枪**、PL-15 手枪、PSh-97 DJETA 防暴头盔、**PR-Taran 警棍**；不穿戴护甲（高血量补偿）
- **⚠️ 核心机制：** 当他掏出 **PR-Taran 警棍**时，**附近玩家手持武器会强制卡壳**（Panic attack 效果），持续到他收棍为止。对策：使用不易卡壳的武器（如 PPSh-41）或保持距离
- **背景：** 被多次指控保护 Kaban 的生意——所有指控者要么改口要么失踪
- **掉落：** 警棍（近战武器，任务物品）

### 🎯 Zryachiy（灯塔 Boss）

- **主场：** Lighthouse 水处理厂**岛屿**（桥梁禁区）
- **HP：** **1,655 —— 全游戏最高**（头 175 / 胸 450 / 腹 270 / 手臂 190×2 / 腿 190×2）
- **身份：** **Lightkeeper 的贴身保镖**，守卫灯塔半岛水处理厂岛屿
- **护卫：** 带有**护卫小队**——主动攻击护卫会触发全岛敌对锁定
- **搜刮与击杀（重要）：** **水处理厂无需击杀即可搜刮** —— 绕开其巡逻范围即可安全进入；击杀他会在特定情形下（如携带相关任务道具）**降低与 Lightkeeper 的关系**，获得成就"盲眼守望者（Blind Overseer）"。社区已知存在**无损击杀与关系修复途径**（如不携带相关任务道具进场、任务顺序调整）
- **策略含义：** 要 Lightkeeper 的恩惠线还是他的掉落，进场前自行权衡 —— 两者并非不可兼得

### 🎯 The Goons（暴徒小队）

见**卷二·派系**专条（Knight 1,120 HP / Big Pipe 榴弹手 / Birdeye 静音狙击手；流动四图各 15–20% + Icebreaker 必刷并随行 2 名 Rogues）。

### 🎯 The Wedge（楔子）

- **全名：** Thomas ｜ **阵营：** Black Division
- **主场：** Icebreaker —— 三层健身房
- **HP：** 自身 880、护卫 880（头 70 / 胸 170 / 腹 140 / 手臂 120×2 / 腿 130×2）
- **地位：** Black Division 指挥官，守卫 Icebreaker 与 Terminal

### 🎯 Partisan（游击队）

- **主场：** **Customs、Woods、Shoreline、Lighthouse 四图各约 20%**，无固定刷新点，全图游荡
- **HP：** 950（头 80 / 胸 220 / 腹 190 / 手臂 110×2 / 腿 120×2）
- **风格：** 独行猎手型 —— **绊线与地雷伏击**、静音穿行灌木、开战前往往你已先触发他的陷阱；优先猎杀低业力（低 Karma）PMC
- **背景：** 0.15 版本加入；老游击队员，视森林与小路为私人猎场；与 Jaeger 立场相近

### 🎯 Cultists / Sectarians（教派）— 俗称"邪教徒"

- **出没：** Woods、Shoreline、Customs、Factory（夜间）、Ground Zero（仅 21+ 级队列）；活动时间 **22:00–07:00**
- **HP：** 祭司 850 / 战士 850（每队 2–4 名战士，分图兵力不同）
- **特征：** 潜伏草丛**无声接近**，涂毒祭祀匕首近战——"未知毒素"约 140 HP/分钟且**撤离后仍持续**；祭司应最后击杀
- **刷新参考：** 主力图约 20%，Factory / Ground Zero 约 2%–3%（随赛季波动）
- **关联：** 与 Lightkeeper 关系密切（授予"教派护符"）；详见卷二·派系专条

### ⚙️ Raiders 与 Rogues（非传统 Boss 势力）

- **Raiders：** Reserve 的精锐 AI 小队（2–4 人），全改装武器 + 高级护甲 + 战术协同，按开关/事件机制刷新；**Season 1（KORD BREACH）中 Labs 的 Raiders 由 Black Division 替代**——详见卷二
- **Rogues：** Lighthouse 水处理厂常驻前 USEC 势力，亦见于 Icebreaker —— 详见卷二
- **Lighthouse 的"传统 Boss"是 Zryachiy**

## Terminal 轮换 Boss 机制

Terminal 采用**轮换 Boss** 制：单次突袭只刷新其中一位，候选池共 **5 位** —— **Sanitar、Glukhar、Reshala、Tagilla、Killa**（各约 20% 参考权重，随赛季调整），另伴随 **Black Division** 守卫。以官方 Wiki 实时数据为准。

## 击败通用提示（战术要点）

- **爆头与高穿弹** 对重甲单位（Killa 6 级面罩、Tagilla 胸甲）是唯一稳定解
- **无甲 Boss（Kaban、Kollontay、Reshala）** 高肉伤弹效率最高 —— 但先把他们的护卫清干净
- **腿部无甲** 是 Killa 等重甲单位的公开弱点
- **Boss 护卫往往是真正的威胁** —— 先清护卫再点名是通行策略（Reshala 战即典型：他躲着，他的人冲着）
- **Zryachiy / Lightkeeper 线**：搜刮水处理厂不必杀他；是否击杀取决于你要 Lightkeeper 关系还是他的掉落（击杀有关系代价，存在规避方法）
