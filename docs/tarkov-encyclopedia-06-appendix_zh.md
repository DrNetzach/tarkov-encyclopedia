## 一、经济系统

### 货币

| 货币 | 符号 | 主要用途 |
| --- | --- | --- |
| 卢布 | ₽ | 绝大多数交易 |
| 美元 | $ | Peacekeeper、Lightkeeper |
| 欧元 | € | Lightkeeper、特定高级交易 |

### 跳蚤市场（Flea Market）

- 玩家间自由交易的在线市场，价格由供需决定
- 需达到等级门槛解锁（具体等级随版本调整）
- 稀有物品（钥匙卡、Boss 掉落）价格极高且波动剧烈，实时行情以 tarkov.dev / tarkov-market 为准

### 以物易物（Barter Trade）

部分商人接受特定物品交换装备 —— 如用稀有钥匙换武器、医疗物资换护甲。高级电子元件与任务物品常以 barter 形式流通。

### 忠诚等级与声望

- 商人 4 级忠诚制（LL1–LL4）：任务 + 消费额 + 等级三重门槛（详见卷三）
- **Scav 业力（Karma）：** 范围约 **-7.0 至 +6.0**，影响 Fence 价格、Scav 世界行为与合作撤离机制
- **商人关系网：** Prapor–Therapist–Mechanic–Jaeger 盟；Skier–Peacekeeper–Ragman 盟；两轴对立

### 保险与容器

- 多数地图装备可投保（死亡后由商人邮寄返还）；**Labs 保险无效**
- 保险箱（Secure Container）提供死亡保底携带格

## 二、术语表

| --- | --- |
| **PMC** | 私人军事公司承包商（玩家角色类型：USEC / BEAR） |
| **Scav** | 拾荒者 —— 本地武装平民；玩家可 Scav 身份进入突袭 |
| **Rogue** | 前 USEC 叛变者（俗称"叛变者"）—— 1.1.5 起驻防 Lighthouse 山区木屋（亦见于 Icebreaker） |
| **Raider** | 精锐 AI 武装小队（Labs / Reserve；Season 1 中 Labs 由 Black Division 替代） |
| **Boss** | 控制特定区域的强力 NPC（见卷四） |
| **Cultist / Sectarian** | 教派邪教徒（俗称"邪教徒"），夜间限定刷新（22:00–07:00） |
| **Black Division** | 最新最致命的 AI 精锐派系（俗称"黑色军团"，Season 1） |
| **HP** | 生命值 |
| **AV / 护甲等级** | 防护等级（游戏内 1–6 级体系，6 级最高） |

| **TerraGroup** | 冲突幕后跨国企业 |
| **OMON** | 俄罗斯特种警察/防暴部队（Ground Zero 参战方） |
| **BTR** | 轮式装甲运兵车 —— Streets 等地图的巡逻重火力，可交互 |
| **The Tour / Falling Skies / The Ticket** | 1.0 主线关键章节（详见卷七） |
| **四结局** | 拯救者 / 幸存者 / 债务人 / 堕落者（Steam 成就官方中译，详见卷七） |
