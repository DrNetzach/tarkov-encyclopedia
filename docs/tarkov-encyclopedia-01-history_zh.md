## 一、诺文斯克特别经济区（Norvinsk SEZ）

**位置：** 俄罗斯西北部，与圣彼得堡隔芬兰湾相望。

**双城格局：**

- **塔科夫市（Tarkov）** — 主要冲突区。拥有高速铁路、大型港口、公路网、工业区和资源精炼设施。
- **诺文斯克市（Norvinsk）** — 经济区金融中心，办公楼与金融机构聚集，通过一座大桥与塔科夫相连。

**建立背景：** 2010年代初"北溪"天然气管道建设期间，克里姆林宫设立特别经济区，以特殊税收地位和政策倾斜吸引国际企业入驻。该地区现实原型大致参照莫斯科附近的斯科尔科沃（Skolkovo）创新中心。TerraGroup 在此建立了重要业务据点。

## 二、TerraGroup Corporation（泰拉集团）

**性质：** 跨国综合企业，业务涵盖制药、材料科学、农业科学、生物工程和物流，获得了开发诺文斯克特区的独家权利，是整个地区的核心投资方。

**暗面 —— TerraGroup Labs（泰拉集团实验室）：**

- 公开承诺带动经济复苏，暗中进行**非法生物研究与武器试验**
- 使用生物武器进行**人体实验**，其他突破伦理底线的活动
- 罪证物品在 RAID 短片中有过呈现
- 游戏内以"实验室（The Lab）"形式作为可突袭地点出现——需要钥匙卡才能进入的高度安保地下设施

**冲突中的角色：** 雇佣 USEC 作为私人安保力量，用于保护设施、阻碍地方当局调查、为非法行动提供武装掩护、与 BEAR 进行代理人战争。**随着冲突升级，TerraGroup 最终抛弃了 USEC**，撤回支持，将承包商遗弃在战区。

**叙事地位：** 塔科夫政治丑闻的震中，"合同战争"的根本原因，一切混乱的幕后推手。

## 三、冲突时间线

| 时间 | 事件 |
| --- | --- |
| 1999 | **USEC 成立** —— 美国安保公司 **KerniSEC** 与英国海上贸易保护公司 **Safe Sea** 合并 |
| 2004 | TerraGroup 代理接触 USEC，USEC 开始为 TerraGroup 工作 |
| 2010年代初 | 北溪管道建设期间，诺文斯克特别经济区成立并进入繁荣期 |
| **2011年10月24日** | **BEAR 由俄罗斯联邦秘密法令正式创建**（成员为现役/退役特种部队，伪装成 PMC 的国家级力量，任务是调查 TerraGroup） |
| ~2011 | TerraGroup 丑闻在塔科夫爆发，政治对峙开始 |
| ~2011 + 6个月 | 政治对峙升级为武装冲突 —— **合同战争（Contract Wars）爆发** |
| 2011–2015 | 合同战争肆虐。TerraGroup 进行非法研究，USEC 保护其资产；双方在泰国、哈萨克斯坦、伊朗等地亦有海外代理冲突 |
| 合同战争中期 | **TerraGroup 抛弃 USEC**，承包商被困战区 |
| 战后 | 俄罗斯政府封锁诺文斯克地区，边境关闭，联合国维和部队干预收效甚微 |
| 当前（游戏时间） | 地区成为无法无天的战区，PMC 为生存和逃离而战 |

> **注：** 海外代理冲突（泰国、哈萨克斯坦、伊朗）的确切时间在不同资料中记述不一，一般理解为合同战争前后。

## 四、合约战争（Contract Wars）

### 起因链条

1. TerraGroup 的非法活动被俄罗斯当局发现
2. 俄罗斯政府以秘密法令组建 BEAR，调查并对抗 TerraGroup
3. TerraGroup 雇佣 USEC 保护其行动、阻碍调查
4. 两家 PMC 直接冲突 —— 最初在海外（泰国、哈萨克斯坦、伊朗）进行代理人作战，随后在诺文斯克地区正面交锋
5. 冲突不断升级，直至俄罗斯政府封锁整个地区

### 定义

合约战争（游戏内部编年史为 2011–2015 年）是一场残酷的企业间武装冲突，代表了从政治丑闻到全面战争的升级过程，为塔科夫灾难奠定了基础。战斗双方为：

- **USEC** —— 保护 TerraGroup 非法活动、阻碍调查
- **BEAR** —— 揭露 TerraGroup Labs 的非法活动、终结冲突

## 六、封锁后的现状与叙事核心

### 氛围

诺文斯克地区是饱经战火、处于崩溃后的区域：基础设施崩塌，建筑损毁或被遗弃，该地区实际上已与外界隔绝。拾荒者、叛逃的 PMC 操作员、残余军事人员和绝望的平民在这个无法无天的环境中争夺资源。

### "逃离"的叙事核心

核心前提是玩家**被困**在诺文斯克地区——边境被俄罗斯军方封锁。每一次突袭都是为了生存、获取资源和寻找逃离之路的绝望尝试。1.0 正式版的主线与结局结构见**卷七·关键剧情人物与主线**。

### 道德灰色地带

塔科夫没有明确的"好人"：

- **BEAR** 是伪装成 PMC 的秘密军事行动
- **USEC** 是企业雇佣兵
- **Scavs** 是绝望的平民变成的罪犯
- **商人们** 各有自己的议程和黑暗历史
- **TerraGroup** 是一切混乱的幕后推手

### 竞技场（The Arena）

塔科夫内部存在有组织的死亡竞技——角斗士式元素，在无法无天的区域中为娱乐和利润而战（对应独立作品《Escape from Tarkov: Arena》）。
