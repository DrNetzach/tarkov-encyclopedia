# 逃离塔科夫百科 · 卷二：派系势力

## 一、USEC（United Security，联合安保）

- **全称：** United Security（联合安保）
- **成立：** 1999 年，由美国安保公司 **KerniSEC** 与英国海上贸易保护公司 **Safe Sea** 合并而成
- **性质：** 西方 PMC，全球雇员 7,500 人以上
- **雇用方：** TerraGroup Corporation（自 2004 年起）
- **人员构成：** 主要为前北约军事人员（美国和英国退役军人），曾与英美政府机构合作（包括伊拉克行动）
- **装备风格：** 西方/北约制式武器 —— AR 武器系统、远程光学瞄具、深度武器改装；常戴沙色 "USEC" 棒球帽
- **战争角色：** 最初执行防御性任务（保护企业资产），随着冲突升级转变为占领力量；在合同战争期间保护 TerraGroup 的非法活动并阻碍调查
- **关键转折：** 冲突升级后 **TerraGroup 抛弃了 USEC**，操作员被困在诺文斯克战区
- **Rogues 的前身：** 部分选择不撤离的 USEC 成员演变为 Rogues（见下）
- **玩家可选阵营之一**

## 二、BEAR（Battle Encounter Assault Regiment，战斗突击团）

- **全称：** Battle Encounter Assault Regiment（战斗突击团）
- **创建：** **2011年10月24日**，由俄罗斯联邦秘密法令正式创建
- **性质：** 俄罗斯国家支持的 PMC —— 据称是伪装成 PMC 的俄罗斯武装力量（为规避直接介入的外交成本而设的"代理人"）
- **人员构成：** 现役及退役特种部队（Spetsnaz）军官，来自俄罗斯及其他斯拉夫语系国家；**必须有军事服役经历**，选拔制保证训练水平
- **使命：** 调查和对抗 TerraGroup 的非法活动，消除西方影响力
- **装备风格：** 最好的俄制武器，包括改装 **AK-12** 作为标准装备，擅长近距离战斗
- **历史：** 成立后曾被承包给非政府机构以掩盖与克里姆林宫的关系；与 USEC 的交手从海外（泰国、哈萨克斯坦、伊朗）延续到诺文斯克正面战场
- **玩家可选阵营之一**

## 三、Scavs（拾荒者）

- **组成：** 本地幸存者、平民、前军人、罪犯的松散联盟
- **领导：** 去中心化，各群体跟随自己的 Boss
- **特点：** 未经训练、装备简陋，但**人数众多**；资源丰富、危险、不可预测
- **行为：** 见面可能开枪也可能放过其他 Scav（包括玩家 Scav）；对 PMC 敌对
- **玩家机制：** 玩家可作为 Scav 携带随机装备进入突袭（冷却时间制）
- **Fence 关系：** Scav 业力（Karma）系统直接影响 Fence 商店价格与 Scav 世界的行为

## 四、Scav Raiders（突袭者 / 精锐拾荒者）

- **组成：** 前 PMC 操作员、具有战斗/战术训练的当地居民及其他熟练战士
- **特点：** 装备和训练水平远超普通 Scav —— 军用级武器与护甲、全改装武器、稀有弹药
- **战术：** 侧翼包抄、压制射击、协调移动、有效使用手雷
- **主要据点：** **Reserve（储备站）**；TerraGroup Labs 在非替换赛季同样出现。2–4 人小队巡逻
- **敌对：** 对所有派系玩家敌对
- **Season 1（KORD BREACH）特别规则：** Labs 的 Scav Raiders **由 Black Division 替代**，Raiders 仅在 Reserve 刷新
- **触发机制：**
- **Labs（非替换赛季）：** 全图自然刷新；激活任一撤离开关有概率引来增援小队
- **Reserve：** 开局在地下指挥区刷新；激活 D-2 电源开关、装甲列车到站、拉动 hermetic 密封门拉杆均可触发额外刷新

## 五、Rogues（叛变者 / 游骑兵）

- **组成：** 前 USEC 特工 —— 冲突后**选择不撤离、加固防守**的 USEC 成员
- **据点（1.1.5 起）：** **Lighthouse 山区木屋（Chalet）一带** —— 1.1.5.0 起 Rogues 已从水处理厂整体换防至此；水处理厂的**固定武器全部拆除**、危险区大幅缓解。亦出现于 **Icebreaker（0/1 层）**
- **行为规则：**
- **对 BEAR 玩家：直接开火**，全距离无警告（反映挥之不去的派系敌意）
- **对 USEC 玩家：** 近距离内保持中立（具体触发距离随情况浮动），一旦 USEC 开枪/杀伤/进入禁区即**永久敌对**
- **对 Scav：** 不会一眼敌对 —— 靠得太近或先行开枪即视为挑衅，此后整局视为敌对
- **装备：** M4A1、HK416、SCAR 系列、4–5 级护甲、面罩头盔、夜视仪（夜间）、固定重机枪
- **战术：** 巡逻路线 + 交叉火力 + 地形架枪，2–3 人小组运用军事战术，全自动射击精度极高，远强于普通 Scav（1.1.5 起水处理厂原固定武器已全部拆除，架枪点转移至 Chalet 一带）

## 六、Cultists / Sectarians（教派 / 邪教徒）

- **性质：** 秘密宗教/邪教组织，夜间活动的神秘长袍人物
- **活动时间：** **游戏内时间 22:00–07:00**（夜间限定），日出后从地图消失
- **编成：** 一名**祭司（Priest，850 HP）** + **2–4 名战士（Warriors，850 HP）**——分图兵力：Factory 2–3、Customs 4、Woods 4、Shoreline 3–4
- **攻击方式：** 潜伏在草丛/高草中**无声移动**，使用**涂毒祭祀匕首**进行近战偷袭（祭司的 Cultist knife 会造成"未知毒素"持续伤害）；亦可使用常规武器远程战斗
- **刷新地图：** Woods、Shoreline、Customs、Factory（夜间）、**Ground Zero（仅 21+ 级队列）**；Woods/Shoreline/Customs 参考约 20%，Factory 与 Ground Zero 约 2%–3%（随赛季波动）
- **与 Lightkeeper 的关联：** Lightkeeper 与教派分子关系良好，会授予独特物品"教派护符（Sectarian Amulet）"
- **行为细节：** 战士通常无视 Scav 与其他 Boss（除非被挑衅）；祭司在玩家靠得太近时可能主动攻击；祭司应最后击杀

## 七、The Goons（暴徒小队，俗称"三狗"）

流动 Boss 小队，不绑定单一地图，在多张地图间巡回：

| 成员 | 定位 | 特征 |
| --- | --- | --- |
| **Knight（骑士）** | 队长 | USEC 逃兵（不服从总部命令），戴标志性**死亡骑士面具**；总 HP **1,120**（头 80·无甲 / 腿 150×2·无甲 / 胸 CPC 挂板）；战斗中积极拉近距离。曾与 Big Pipe 在非洲、南美、亚洲并肩作战 |
| **Big Pipe（大管）** | 掷弹兵 | 标志性武器为**榴弹发射器**，投掷手雷将敌人从掩体中赶出 |
| **Birdeye（鸟眼）** | 狙击手/观察哨 | 控制广阔区域，最先发现敌人；**脚步声比普通 Boss 安静** —— 你死的时候根本不知道谁开的枪 |

**巡回地图与参考刷新率：** Customs / Woods / Lighthouse / Shoreline（各约 **15–25%**，多源浮动）、**Icebreaker（100% 必刷，Knight 出场并随行 2 名 Rogues）**

*（刷新率随赛季调整，此处为参考值。出生参考：Customs 要塞与西北 Scav 地堡、Woods 西北 Scav 地堡、Lighthouse 水处理厂北楼与别墅、Shoreline 气象站）*

**特点：** 三人协同作战、无线电共享敌情、高度协调；掉落死亡骑士面具、限量 CPC 挂板背心等高价标志性物品。

## 八、Black Division（黑色分队）

- **性质：** 最新、最致命的 AI 派系 —— 精英中的精英
- **HP：** 每名操作员 **约 880**（含 The Wedge 的护卫；部分早期资料记为 790，以当前 Wiki 为准）
- **特点：** 训练有素、装备精良，以紧密协调的编队作战
- **指挥官：** Boss **The Wedge（楔子，全名 Thomas）** —— 驻 Icebreaker 三层健身房，自身及护卫 HP 均为 880
- **据点与出现：** 守卫 **Icebreaker** 与 **Terminal**；Season 1 期间**替代 Scav Raiders 驻守 Labs**，并出现在 **Ground Zero、Streets of Tarkov**（部分资料提及 Shoreline，存疑待核）
- **威胁等级：** 除 Scav Boss 外全游戏最高
- **历史渊源：** Contract Wars 网页游戏时期已有"Black Division"设定（精英 PMC 中的传闻部队）

## 九、其他武装力量

- **OMON（俄罗斯防暴警察）：** Ground Zero 战场的参与方之一（与 USEC 冲突激烈）
- **BTR 装甲车：** Streets 等地图上的巡逻重火力单位，可交互（付费运送等）

## 十、阵营关系速查

| 攻击方 → 目标 | 行为 |
| --- | --- |
| USEC ↔ BEAR | 直接敌对，互相开火 |
| Rogues → BEAR | 全距离见面即开火 |
| Rogues → USEC | 近距离中立，挑衅后永久敌对 |
| Rogues → Scav | 靠太近/开枪挑衅后整局敌对 |
| Scav → PMC | 敌对；对其他 Scav 中立 |
| Cultists → 所有人 | 敌对（仅夜间 22:00–07:00） |
| Boss 势力 → 入侵者 | 领地防御性敌对 |
| Black Division → 所有人 | 敌对（精英单位） |
| Raiders → 所有人 | 敌对（Labs 替换赛季除外） |
| Lightkeeper → 教派 | 关联友好 |
