## 使用说明

- **动态数值**（Boss 刷新率、市场价格、撤离点细则）随赛季变动，引用时以游戏内与 [tarkov.dev](https://tarkov.dev) 实时数据为准
- **存疑与未核内容**集中标注于[卷六 · 引用说明](tarkov-encyclopedia-06-appendix_zh.md)的"已知未决项"清单，引用建议回避或挂"存疑"注
- 术语检索以官方名/英文名为锚点，社区俗称（大妈、机哥、三狗、小鹿……）对照见卷六
